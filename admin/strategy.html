Current Model Assessment

The core tension: the site is positioned as both a ministry ("Bible-based teaching") and a content platform/school — which limits commercial monetization. Donors give to a ministry; sponsors pay for audience reach. These are different motivations with different expectations.

Better Business Model Options

Option B: Paid Digital Products

  • Sell books individually for GH¢50-150 each ($3-9) via Flutterwave
  • Bundle all 4 books for GH¢300 ($17)
  • Add paid video teachings/courses at GH¢200-500 ($12-30)
  • Keeps the "ministry" feel while actually charging for content

Recommended: Hybrid Model Best Fit

Combines four revenue streams so supporters self-select based on how they view the work:

  • Donations (one-time) — for those who see it as ministry
  • Digital products / books for sale — for those who see it as content
  • Sponsorships — for businesses reaching the audience
  • Recurring Patron tiers — for ongoing community support

This avoids the ministry-vs-commerce conflict because people self-select based on how they view the work.

How to Measure Effectiveness

You need metrics, not guesses. Analytics infrastructure is now in place:

Existing Free Tools Available

  • Cloudflare Web Analytics — auto-injected by Cloudflare Pages when enabled in dashboard ✓
  • /api/track endpoint — logs page views + custom events (donation_started) to D1 events table, with device type, country, traffic source
  • Donation funnel tracking — donation_started event fires on checkout open, enabling abandoned-donation recovery
  • Abandoned donation recovery cron — runs hourly, checks for donation_started events >24h old with no completed donation, queues reminder email
  • Flutterwave dashboard — shows donation amounts, frequency, currency
