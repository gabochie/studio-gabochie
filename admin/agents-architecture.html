How It Works

  • Human supervision: All AI output is reviewed through the Command Center dashboard before publishing. The human sets policy, approves content, and monitors agent health.
  • Orchestration: The Orchestrator runs on a cron schedule (every 15 min) and manually via "Process Now". It pulls from the agent queue and dispatches work.
  • Dispatching: The Task Processor reads the queue and routes work to the appropriate agent type. Each agent type has specific tools and prompt templates.
  • Sub-Agents: Any agent can spawn sub-agents for parallel subtasks. Sub-agents are tracked via parent_run_id and sub_agent_count on the parent run record.
  • Workflows: 5 pre-built automated workflows run on cron: abandoned checkout recovery, dormant subscriber reactivation, post-purchase upsell, weekly analytics report, daily fulfillment check.
  • Data flow: Agents read/write D1 via query_d1 tool, generate content via OpenAI call_ai, send emails via queue_email, and create tasks via save_to_tasks for human review.
